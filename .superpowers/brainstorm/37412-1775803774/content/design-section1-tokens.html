--transition-slow: 300ms ease;
--transition-spring: 200ms cubic-bezier(0.34,1.56,0.64,1);

/* Step completion pulse (green flash) */
@keyframes step-complete { 0%,100% { opacity:1 } 50% { opacity:0.6 } }

/* File write flash (subtle blue highlight) */

/* Build phase fade-in */
@keyframes fade-up { from { opacity:0; transform:translateY(4px) } to { opacity:1; transform:none } }

1D — Border Radius Refinement

Current --radius: 0.5rem (8px). We'll add intermediate steps: 4px for dense UI elements (badges, chips, code labels), 8px for cards/panels, 12px for modals/popovers, full for pills/avatars. These map to existing Tailwind scale (rounded-sm, rounded-md, rounded-lg, rounded-full) — no new classes needed.
