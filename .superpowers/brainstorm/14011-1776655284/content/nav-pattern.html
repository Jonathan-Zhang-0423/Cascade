Mobile navigation pattern

How does the user switch between Chat and Preview on their phone?

A

Bottom tab bar

Persistent tabs at the bottom — Chat | Preview. Native iOS/Android feel. Thumb-friendly. Always visible.

B

Floating toggle button

A pill-shaped button (e.g. "Preview ▶") that floats above the chat. Tapping it full-screens the preview with a back arrow to return.

C

Swipe gesture

Swipe left/right between Chat and Preview panels. Tab indicators at top show which pane is active.
