## Mandatory Technical Specifications & Requirements
### 1. Dependency Setup
Confirm and install the required dependencies for this phase:
- Core: `ai` (Vercel AI SDK)
- LLM connector: `@ai-sdk/volcengine` (for Doubao Seed 2.0 Code integration, with pre-configured Volcano Engine API keys)
- UI components: Existing Shadcn UI `input`, `button`, `card`, and `scroll-area` components (already initialized in the Phase 1 project)

### 2. API Route Development (`app/api/chat/route.ts`)
- Use Next.js 15 App Router Route Handler standard
- Initialize the Volcano Engine client with `createVolcengine` from `@ai-sdk/volcengine`, and explicitly set the model to `doubao-seed-2-0-code`
- Implement streaming response with the `streamText` function from the Vercel AI SDK
- Support full conversation history passing between the frontend and the model
- Include basic error handling for API failures and invalid requests

### 3. Zustand State Management (`store/chatStore.ts`)
- Define strict TypeScript types for all chat-related state
- Core state to manage:
  - `messages`: Full conversation history array, with `role` (user/assistant) and `content` fields
  - `input`: Current user input value in the chat box
  - `isLoading`: Boolean flag for AI generation loading state
- Core actions to implement:
  - Update user input value
  - Send user messages and handle streaming AI responses
  - Append incremental streaming content to the assistant message
  - Reset the full chat history
  - Stop ongoing AI generation
