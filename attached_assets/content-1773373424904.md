Plan mode introduces a new way of chatting with Replit Agent that focuses on asking questions, brainstorming, and planning your work.

![Agent chat interface in Plan mode](https://mintcdn.com/replit/F1Uusll-kiG71hlC/images/replitai/plan-mode-overview.png?fit=max&auto=format&n=F1Uusll-kiG71hlC&q=85&s=247073a58dc0196b6fb486fd32653fbd)

## [​](https://docs.replit.com/replitai/plan-mode\#what-is-plan-mode)  What is Plan Mode?

Plan mode enables you to:

- **Brainstorm ideas** and explore different approaches to your project
- **Plan development work** with structured task lists
- **Collaborate with AI** on project architecture and feature planning
- **Get strategic guidance** and ask questions without modifying your project’s code or data
- **Transition seamlessly** to Build mode when you’re ready to implement

The default mode is now referred to as **Build** mode.Unlike Build mode, Plan mode focuses on planning and ideation, helping you think through projects before writing code.

## [​](https://docs.replit.com/replitai/plan-mode\#getting-started)  Getting Started

### [​](https://docs.replit.com/replitai/plan-mode\#accessing-plan-mode)  Accessing Plan Mode

Plan mode is available in any Replit App that has Agent enabled. To access it:

1. **Open your Replit App** workspace
2. **Look for the mode selector** at the bottom left of the chat input box
3. **Choose Plan mode** from the dropdown

![Mode selector showing Plan mode and Build mode options](https://mintcdn.com/replit/F1Uusll-kiG71hlC/images/replitai/plan-mode-selector.png?fit=max&auto=format&n=F1Uusll-kiG71hlC&q=85&s=19e04b960deaf929b954f0639ffa6aa3)

## [​](https://docs.replit.com/replitai/plan-mode\#key-features)  Key Features

### [​](https://docs.replit.com/replitai/plan-mode\#task-planning)  Task Planning

Plan mode excels at breaking down complex projects into manageable tasks. Provide the Agent some requirements and it will generate an ordered task list of the development tasks necessary to complete your request.

![Generated task list with priorities and dependencies](https://mintcdn.com/replit/F1Uusll-kiG71hlC/images/replitai/plan-mode-task-list.png?fit=max&auto=format&n=F1Uusll-kiG71hlC&q=85&s=6e5a76ea4a3da7840f6ac26f4e3e608e)

### [​](https://docs.replit.com/replitai/plan-mode\#collaborative-brainstorming)  Collaborative Brainstorming

Work together with AI to explore different approaches:

- **Multiple solution paths** for complex problems
- **Pros and cons analysis** of different approaches
- **Risk assessment** and mitigation strategies

## [​](https://docs.replit.com/replitai/plan-mode\#workflow-from-planning-to-building)  Workflow: From Planning to Building

### [​](https://docs.replit.com/replitai/plan-mode\#1-planning-phase-plan-mode)  1\. Planning Phase (Plan Mode)

Start your development process in Plan mode:

- **Define your project scope** and objectives
- **Break down requirements** into specific features
- **Plan your architecture** and technology stack
- **Create a development roadmap** with milestones

### [​](https://docs.replit.com/replitai/plan-mode\#2-task-approval)  2\. Task Approval

When Agent generates a task list:

- **Review** the proposed tasks
- Select **Start building** to approve the plan

or, keep chatting to refine the plan.

### [​](https://docs.replit.com/replitai/plan-mode\#3-transition-to-build-mode)  3\. Transition to Build Mode

When you’re ready to start implementing:

- **Click “Start building”** to approve the plan
- **Agent automatically switches** to Build mode
- **Agent begins implementation** of approved tasks
- **Track progress** through the development phase

Plan Mode usage follows the same effort-based pricing as other Agent interactions. You are charged for all Agent work in Plan Mode, including answering questions, providing guidance, and generating task lists. Charges scale up for more complex requests, or requests in longer context conversations.**All Agent interactions are billable** \- whether Agent responds with text guidance or makes code changes, there is always a charge, though smaller requests cost less.

## [​](https://docs.replit.com/replitai/plan-mode\#use-cases)  Use Cases

### [​](https://docs.replit.com/replitai/plan-mode\#feature-planning)  Feature Planning

Ideal for adding new functionality:

- **Break down complex features** into implementable tasks
- **Plan database changes** and API modifications
- **Design user interface** and user experience flows
- **Consider edge cases** and error handling

### [​](https://docs.replit.com/replitai/plan-mode\#learning-and-exploration)  Learning and Exploration

Excellent for educational purposes:

- **Understand different approaches** to solving problems
- **Learn about new technologies** and frameworks
- **Explore design patterns** and best practices
- **Get guidance** on development methodologies

![Asking questions to Agent in Plan mode](https://mintcdn.com/replit/F1Uusll-kiG71hlC/images/replitai/plan-mode-conversation.png?fit=max&auto=format&n=F1Uusll-kiG71hlC&q=85&s=237a4802c3090561db5b22bc1a705dc8)

## [​](https://docs.replit.com/replitai/plan-mode\#best-practices)  Best Practices

### [​](https://docs.replit.com/replitai/plan-mode\#effective-prompting)  Effective Prompting

To get the most out of Plan mode:

- **Be specific** about your project requirements
- **Ask follow-up questions** to clarify AI suggestions
- **Request examples** when discussing complex concepts
- **Discuss trade-offs** between different approaches
- **Iterate on ideas** before committing to implementation
- **Save important decisions** by referencing them in follow-up conversations
