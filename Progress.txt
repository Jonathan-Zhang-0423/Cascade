============================================================
CODESTART — MOBILE-FIRST DEVELOPMENT PLATFORM
============================================================

Project Pivot: From browser-based web IDE to mobile-first
all-in-one development platform for building production-ready
iOS & Android apps using AI coding agents.

Supported Frameworks:
  - React Native (Expo) — primary, most beginner-friendly
  - Flutter (Dart)
  - SwiftUI (iOS-only)
  - Kotlin / Jetpack Compose (Android-only)

Supported Languages:
  - TypeScript / JavaScript (React Native)
  - Dart (Flutter)
  - Swift (SwiftUI)
  - Kotlin (Jetpack Compose)

AI Providers (unchanged):
  - Doubao (ByteDance) — default
  - Kimi K2.5 (Moonshot AI)
  - MiniMax-M2.7
  - GLM-5 (Zhipu AI)

============================================================
ARCHITECTURE DECISIONS
============================================================

1. React Native with Expo as primary framework
   - Most accessible for beginners (JavaScript/TypeScript)
   - Expo handles native complexity (no Xcode/Android Studio needed)
   - Expo Web enables browser-based preview before device testing
   - EAS Build provides cloud compilation

2. Multi-framework via template system
   - Each framework is a project template with its own file set
   - Skill loader detects framework and injects correct AI skills
   - Agent prompts dynamically switch based on framework
   - Preview adapts to framework (Expo Web, Flutter Web, etc.)

3. Device simulator is a UI chrome layer
   - The simulator is a visual frame around the preview content
   - Content rendering depends on framework:
     - React Native → Expo Web (iframe)
     - Flutter → Flutter Web (iframe)
     - SwiftUI/Kotlin → Static mockup or cloud-rendered screenshot
   - This approach works on Replit without native emulators

4. Cloud builds, not local builds
   - Replit doesn't have Xcode, Android SDK, or Flutter SDK
   - All compilation happens via cloud services (EAS Build, etc.)
   - The IDE sends project files to the build service
   - Built artifacts are downloaded or shared via QR code

5. Preserve existing web development capability
   - Web projects (HTML/CSS/JS) remain fully supported
   - All existing prompts, skills, and features are preserved
   - Framework field in project metadata determines behavior
   - Default new project type changes from "web" to "mobile"

6. PWA over native IDE app
   - Making the IDE itself a PWA is practical on Replit
   - A native mobile wrapper for the IDE can come later if needed
   - PWA gives installable, offline-capable mobile experience
   - Avoids the complexity of building two apps at once

FRAMEWORK COMPARISON
============================================================

| Aspect              | React Native/Expo | Flutter      | SwiftUI      | Kotlin/Compose |
|---------------------|-------------------|-------------|-------------|----------------|
| Language            | TypeScript/JS     | Dart        | Swift       | Kotlin         |
| Platform            | iOS + Android     | iOS+Android | iOS only    | Android only   |
| Beginner-friendly   | ★★★★★             | ★★★★        | ★★★         | ★★★            |
| Browser preview     | Yes (Expo Web)    | Yes (Web)   | No          | No             |
| Cloud build         | EAS Build         | Codemagic   | Xcode Cloud | Gradle cloud   |
| Hot reload          | Yes               | Yes         | Preview     | Preview        |
| Ecosystem           | npm (huge)        | pub.dev     | Apple only  | JetPack        |
| Recommended for     | Beginners, cross  | Cross-plat  | iOS devs    | Android devs   |
